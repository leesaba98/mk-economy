# 매경 시황·세계경제 (mk-economy)

매일경제(mk.co.kr)의 **주식시황**과 **세계경제** 소식을 하루 한 장으로 보는 모바일 홈 화면 앱(PWA)입니다.

- 주소: https://leesaba98.github.io/mk-economy/
- 매일 오전 9시에 `app-data.js` 한 파일만 갱신하면 화면이 바로 바뀝니다(서비스 워커 Network-First).

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 뼈대 + 스타일 (모바일 퍼스트) |
| `app-data.js` | **매일 갱신되는 브리핑 데이터** (요약·지수·기사 목록) |
| `app.js` | 데이터를 화면에 그리는 로직, 탭, 새로고침 |
| `sw.js` | Service Worker (Network-First, 오프라인 시 마지막 화면 유지) |
| `manifest.json` | 홈 화면 추가(PWA) 설정 |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 앱 아이콘 |

## 탭 구성

1. **오늘 한눈에** — 핵심 요약 3~4줄 + 코스피·코스닥·다우·S&P500·나스닥·원/달러·WTI·금
2. **매경 주식시황** — 매일경제 증권/시황 주요 기사 요약 + 원문 링크
3. **매경 세계경제** — 매일경제 세계경제·국제·환율·금리 주요 기사 요약 + 원문 링크

## 데이터 갱신 방법

`app-data.js`의 `meta.updatedAt`, `summary`, `markets`, `stocks`, `world`만 고쳐 커밋하면 됩니다.
수치는 반드시 매일경제 기사 또는 매경 시세판에서 확인한 값만 넣습니다.

> 요약은 매일경제 기사 내용을 바탕으로 정리한 것입니다. 투자 판단과 책임은 투자자 본인에게 있습니다.
